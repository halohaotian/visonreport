# VisonReport i18n Design

## Goal

Add bilingual support (English + Chinese) to VisonReport with English as default, using URL-prefix routing (`/en/...`, `/zh/...`).

## Library

**next-intl** — native Next.js App Router integration, Server Components support, built-in middleware.

## Architecture

```
messages/
  en.json              # English translations
  zh.json              # Chinese translations
src/
  i18n/
    request.ts         # next-intl getRequestConfig
  middleware.ts         # locale detection + redirect
  app/
    [locale]/           # dynamic locale segment
      layout.tsx        # root layout with NextIntlClientProvider
      page.tsx          # landing page
      (auth)/
        login/page.tsx
        register/page.tsx
        pricing/page.tsx
      admin/page.tsx
      visualize/page.tsx
    api/                # unchanged — no locale prefix
```

## Routing Rules

| URL            | Behavior                     |
|----------------|------------------------------|
| `/`            | redirect to `/en`            |
| `/en`          | English landing page         |
| `/zh`          | Chinese landing page         |
| `/en/login`    | English login                |
| `/zh/admin`    | Chinese admin dashboard      |
| `/api/*`       | unchanged, no locale prefix  |

## Language Switcher

Simple toggle in page header: `EN | 中`. Clicking switches between `/en/...` and `/zh/...` by replacing the locale segment in the current path.

## What Changes

- All 7 page files moved into `app/[locale]/` with `useTranslations()` calls
- New `middleware.ts` for locale routing
- New `src/i18n/request.ts` for next-intl config
- New `messages/en.json` and `messages/zh.json`
- `layout.tsx` updated with `NextIntlClientProvider`

## What Does NOT Change

- `src/lib/db.ts` — pure data operations
- `src/lib/auth.ts` — pure utility functions
- `src/app/api/*` — API routes stay at root, no locale prefix
- `src/lib/ai-parser.ts` — AI prompts kept in Chinese (for AI model, not user-facing)

## Scope

- 7 page files to refactor
- ~363 strings to extract and translate
- 3 new infrastructure files (middleware, i18n config, translations)
- 1 new component (LanguageSwitcher)
